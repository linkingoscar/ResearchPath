# PROCESS 工作台说明

## 能力边界

ResearchPath 识别 PROCESS 5.0 编号 1–22、28–29、58–73、75–76、80–92，共 55 个预编程模型；Model 74 不在目录中。全部目录项可以搜索和预览，满足变量类型、中介数量、路径结构与样本条件时可进入统一执行链。

快捷模板覆盖 1、2、3、4、5、6、7、8、14、15、21、22、58、59。其余编号通过完整目录或自定义结构进入。合法但未命中目录编号的自定义拓扑可以保存、检查和导出设计，不能提交统计运行。

当前执行约束：

- X、W、Z 和协变量接受连续变量或 0/1 二分类变量；
- M 只接受连续变量；二分类中介返回 `BINARY_MEDIATOR_NOT_SUPPORTED`；
- 多类别 X 不会被静默转成虚拟变量后冒充支持；
- 运行成功不替代模型假设、诊断和独立数值验证。

## 点按流程

1. 在“更换模型”中选择模板或目录项，也可以从空白 X / Y 槽位创建自定义结构。
2. 在变量库搜索并点选变量，选择角色，再分配到对应槽位；键盘点按和拖放均可使用。
3. 在“变量与控制”“路径与调节”“估计设置”中完成模型配置。
4. 控制变量会创建实际模型节点与方程指派；删除节点或路径会同步清理失效的调节、控制方程和中心化引用。
5. W / Z 连向有多条入边的结果节点时，必须明确选择被调节路径。
6. 先执行结构检查，再冻结规格并运行。冻结后的任何修改、撤销或重做都会使冻结版本失效。
7. 当前运行结果单独展示；结果包、复现包和含数据结果包使用明确区分的下载入口。

## 草稿与状态

- 删除全部路径后的未完成草稿仍可保存并在刷新后恢复。
- 不完整或不受支持的结构不会显示为可运行。
- 角色变更会清理不再适用的关系；撤销和重做同时恢复模型结构与模式标签。
- 切换数据、测量或研究上下文会重新检查适用性，不静默覆盖草稿。
- 运行期间规格锁定；取消只停止该次任务拥有的进程树。

## 视觉与可访问性

专家画布使用独立的冷色视觉层，不向 Data / Analyze / Output 日常工作台泄漏模糊和悬浮卡片样式。浅色、深色、减少动态、forced colors 与窄屏均有回退。主要操作支持键盘，滚动区域不得形成键盘陷阱。
