# 统计方法与报告规范

## 共通原则

- 分析绑定不可变数据版本、规格版本、随机种子和引擎版本。
- 缺失处理、变量变换、中心化、参考组和样本排除必须先于估计明确记录。
- 报告同时给出效应量、区间估计、样本量、诊断和方法限制；不只给 p 值。
- 统计结果由 R 引擎生成，Python 负责编排和契约，前端不得重新计算。
- 回退、退化与剔除必须显式警告：方法失败回退、统计量无法定义、重抽样被剔除、欠定模型，都不允许无声变成 null 或默认值。

### 警告码清单

平台以 `{code, severity, message}` 三元组输出警告，前端与导出必须展示。当前登记的主要警告码：

| 警告码 | 触发条件 | 行为 |
| --- | --- | --- |
| `PARALLEL_ANALYSIS_FALLBACK` | 平行分析失败 | 回退固定因子数并说明失败原因 |
| `PARALLEL_ANALYSIS_ZERO_FACTORS` | 平行分析未支持保留共同因子 | 保留 0 因子诊断，不自动调用至少需要 1 因子的 EFA 拟合器 |
| `MEASUREMENT_EFA_NUMERICAL_FALLBACK` | 高级 EFA 的相关、提取或旋转发生数值降级 | 顶层展示实际降级并保留 diagnostics 细节 |
| `MEASUREMENT_SPLIT_VALIDATION_EXECUTION_MISMATCH` | 主样本、训练集或留出集实际估计过程不同 | 不报告 Tucker congruence，列出三份执行指纹 |
| `NON_FINITE_RESULT_VALUE` | 结果含 NaN/Inf/-Inf | 转为 null，并在 provenance 记录 JSON Pointer 与原始类型 |
| `REGRESSION_UNDERDETERMINED` | 分层回归完整案例 ≤ 待估参数 | 该区块 R²/ΔR² 置 null、`underdetermined=true`，不解释 |
| `PARTIAL_CORRELATION_UNDEFINED` | 偏相关完全共线或零残差变异 | 该对置 null 并列出变量对 |
| `HTMT_UNDEFINED` | HTMT 因题项相关矩阵退化 | 该对置 null 并列出构念对 |
| `HTMT_REPLICATION_DROPPED` | HTMT bootstrap 无效重抽样被剔除 | 报告剔除数量、占比与涉及构念对数 |
| `BOOTSTRAP_REPLICATION_DROPPED` | 中介 bootstrap 无效重抽样被剔除（≤5%） | 报告剔除数量与占比，区间基于有效重抽样 |
| `BOOTSTRAP_REPLICATION_LOSS_EXCEEDS_LIMIT` | 中介 bootstrap 无效重抽样 >5%（错误码，非警告） | 拒绝报告区间并终止，`{code, ...}` 结构化错误 |
| `GROUP_COMPARISON_SKIPPED` | 某组样本不足或组内零方差 | 该变量行 `unavailable=true + reason`，其余继续 |
| `LONGITUDINAL_SINGULAR_FIT` | 增长曲线随机斜率奇异边界 | 斜率与区间标记不可靠 |
| `KMO_SKIPPED_RESOURCE_BUDGET` | 题项数 >800 超出 KMO 求逆预算 | KMO 置 null 并给出可操作提示 |
| `HC3_UNAVAILABLE` | HC3 稳健标准误不可计算 | 不执行经典 vcov 替代，保留不可用原因并要求人工复核（不被其他警告覆盖） |
| `SEM_CR_SUPPRESSED_CORRELATED_RESIDUALS` | 潜变量指标间存在自由相关残差 | 该构念 McDonald's ω 与 CR 置 null 并附 `compositeReliabilityReason=suppressed_correlated_residuals`；α（附 `alphaSampleSize`）与 AVE 照常报告；警告随结果展示与导出，但属于可靠性诊断，不单独触发 `publicationEligible=false` |

新增统计路径的警告必须先在 R 侧产生、再经契约到达前端，禁止前端自行推断回退是否发生。

### 测量学状态化契约（EFA/MAP/PA/split validation）

- **MAP**：候选成分数是 `0..p-2`，`recommendedFactorCount` 直接对应使平均平方偏相关最小的成分数，不得把索引误当成因子数。相关矩阵非正定时返回 `available=false + reason=correlation_matrix_not_positive_definite`，推荐数为 null。
- **平行分析（PA）**：`recommendedFactorCount=0` 是合法诊断，表示模拟阈值未支持共同因子；诊断层不得强制改为 1。实证执行层遇到 0 时不调用至少需要一因子的拟合器，并要求用户如需理论驱动模型应显式选择固定因子数。`correlationType`/`simulationType` 随结果输出；ordinal 数据走 `polychoric` + `ordinal_threshold_preserving`，不可行时 `available=false`，禁止静默降级 Pearson。
- **Requested / executed**：EFA 同时输出 requested/executed correlation、extraction 和 rotation。执行字段表达实际采用值，不能以请求值覆盖回退事实。
- **Split validation**：train/holdout 复用用户选择的管线，并分别记录 primary/train/holdout 的实际执行指纹（相关类型、提取法、旋转、因子数）；三者不一致时返回 `available=false + reason=split_validation_execution_mismatch`，禁止比较不同 estimator 的载荷一致性。
- **数值 fallback**：EFA/PAF/rotation 的降级经 `diagnostics.numericalFallbacks[{stage, requested, used, reason}]` 结构化披露；高级测量结果还必须生成顶层 warning，确保主结果区和导出可见。

## 问卷测量

活动能力包含基础信度/项目分析、EFA/CFA、收敛与区分效度、测量等值性，以及高级工作台中带声明 Target 的连续 ESEM、连续/有序 Bifactor、二元 2PL 与多分类 GRM IRT/DIF。估计器、连续/有序题项处理、缺失策略、反向题和构念结构必须显式；有序 ESEM 尚未开放。

- 基础实证报告不自动执行 ESEM、Bifactor、IRT 或 DIF；这些方法只能在高级问卷测量工作台显式选择题项尺度、估计器和模型规格后执行。基础结果以 `advancedMeasurementBoundary.executedInBaseReport=false` 固化该边界。
- 基础 CFA 在全部题项有序时使用 WLSMV，在全部题项连续时使用 MLR；混合尺度若没有显式异质相关矩阵与相应估计器，返回 `MIXED_SCALE_CFA_REQUIRES_EXPLICIT_MIXED_CORRELATION_ESTIMATOR`，禁止静默整体连续化。
- HTMT 必须记录 `htmtCorrelationSource`：连续题项为 Pearson、有序题项为 polychoric；混合尺度没有受支持的异质相关规格时不运行。nested 数据可给出描述性 HTMT，但普通逐行 bootstrap 不运行。
- 正交 Bifactor 的 ωh 使用总分方差恒等式：分母为 `(Σλg)^2 + Σs(Σλs)^2 + Σθ`。每个特定因子的载荷先求和再平方，不能用全部特定载荷平方和替代。
- SEM/CFA 单因子 CR 与 McDonald's ω 的 Fornell-Larcker 型公式 `(Σλ)²/((Σλ)²+Σ(1-λ²))` 只在指标残差互不相关时成立。SEM 路径在估计后逐构念检测自由相关残差（`parTable` 中 `op=="~~"` 且 `free>0`、`est≠0`）：存在即抑制该构念 CR/ω（置 null + `compositeReliabilityReason`）并发 `SEM_CR_SUPPRESSED_CORRELATED_RESIDUALS`，不得静默输出系统性高估的信度。α 基于 listwise 完整案例计算，与主拟合（可能 FIML）样本口径不同，结果以 `alphaSampleSize` 披露实际 N。

### 确认性测量的样本适切性

CFA 输出同时记录完整案例数、题项数、自由参数数及每参数案例数。平台采用“完整案例不少于 100 且每自由参数不少于 5 个案例”的保守解释护栏；拟合器能返回自由参数数时使用实际值，否则使用简单结构近似 `2p + k(k-1)/2`。该规则用于阻止小样本可计算结果被包装成稳定确认性证据，不是普适样本量定理。即使通过，也必须结合模型复杂度、估计量、分布、收敛和异常解判断。

### 降级透明度

CFA、`factanal` 或相关矩阵估计失败时，代码可能采用 PCA 或单因子特征分解等稳健回退。回退不是等价估计：

- `methodExecution` 必须记录请求方法、实际方法、回退原因和警告；
- 前端结果与 Excel 导出必须展示该信息；
- 报告不得把回退结果写成成功的 CFA/EFA；
- 测试需覆盖主路径和回退路径的契约。

## 回归、PROCESS 与 SEM

当前不提供准实验因果识别。`quasi_experimental` 是预留的内部上下文字段，在产品层显示为“非随机比较”；它不能解锁随机实验切片，也不能把回归、PROCESS、SEM、ANCOVA 或 cluster-robust 线性模型的关联估计升级为因果效应。

横截面只描述时间结构，不保证观测独立。员工嵌套于团队、学生嵌套于班级等单次测量数据必须显式声明 cluster。当前聚类横截面边界包括 ICC(1)、ICC(2)、设计效应与 rwg 聚合证据，以及单一 cluster 的两层 Gaussian LMM；聚合诊断不使用固定阈值自动宣布可聚合，也不等同于已经完成多层建模。请求契约以 `aggregationVariableId` 指定 cluster 聚合变量，以 `groupVariableId` 指定组间比较、测量等值性与 DIF 分组变量；两者语义正交，不能因字段缺失而互相借用。三层、交叉分类、广义结局多层模型仍不在当前活动入口。

基础横截面任务按模块做适用性检查，而不是只检查 overview。nested 上下文允许描述、测量准备和 ICC/rwg 聚合诊断，但普通相关 p 值/Fisher z 区间、行级 HTMT bootstrap、组间检验、单层分层回归和响应面不执行；CFA/EFA 载荷须标为未作 cluster adjustment 的测量准备。若请求组间检验或单层回归，API 返回对应 slice 的 `METHOD_NOT_APPLICABLE_TO_CONTEXT`，要求改用 cluster-aware 或多层规格。

基础横截面推断先登记统一的 `multiplicityFamilyId`，把每个已执行的相关、组间比较和非截距回归系数作为同一 family 内的检验假设；主推断使用声明的 `multiplicityPAdjust`（BH/Holm/none），组件诊断和 pairwise 程序仍保留各自方法并标明不参与主模型选择。模型画布上由用户具名的 hypothesis ID 只通过 ModelSpec `evidenceGraph` 与 edge/effect 绑定，基础实证报告不得虚构未提交的 ID。结果和导出同时保存原始 p、调整 p、family id、family size 与调整方法；界面星号只基于调整 p。`confidenceLevel` 必须从请求传到相关、效应量、回归和报告（默认 0.95，可选 0.90/0.99），单个区间不冒充同时区间，必须明确 `confidenceIntervalsAdjusted=false`。

横截面组间比较的主模型在运行前声明：两组使用 Welch 独立样本 t，三组及以上使用 classical one-way ANOVA；Welch/HC3 是敏感性分析，Brown–Forsythe 只作方差诊断，不能根据 p 值或诊断结果自动切换主模型。普通 OLS 是横截面分层回归主分析，HC3 仅作敏感性分析；欠定回归、HC3 不可用、CFA 数值 fallback 或异常解均不得作为论文主分析自动发布。所有结果必须保留原始、选入、排除、缺失、最终 N、缺失变量计数与缺失模式。

模型画布的边状态遵循描述性推断规则：有置信区间时先判断区间是否跨 0，只有缺少区间时才回退到 p 值；“区间不含 0 / p<.05”不得命名为理论支持，“区间含 0 / p≥.05”也不得命名为无效或零效应。理论解释仍需结合研究设计、效应量、区间宽度、模型诊断、多重性和先验假设。

模型识别目录固定为 PROCESS 5.0：1–22、28–29、58–73、75–76、80–92，
共55个当前可指定的预编程编号；Model 74 不作为可选编号恢复。目录识别只说明
观测变量拓扑与编号模板匹配，不构成因果识别。55 个编号在满足目录规定的中介
数量时均可执行；合法但未命中编号的自定义拓扑仍返回
`executionAvailable=false`。

变量编码边界：PROCESS 编号执行只接受连续或 0/1 二分类的 X；M（中介变量）
只接受连续变量。二分类中介在运行前守门拒绝并返回
`BINARY_MEDIATOR_NOT_SUPPORTED`：logit 方程的中介路径系数与 OLS 结果方程系数
直接相乘不构成可解释的间接效应，不得照常输出。多类别 X（官方
宏的 mcx 编码，如 Hayes 书内 protest 示例）不执行，运行前守门拒绝并返回
`PROCESS variable x must be continuous or binary`。这些拒绝是显式产品边界而非
回退：不得把多类别 X 静默转成 treatment/Helmert 哑变量后按编号模型执行，
也不得把二分类 M 按连续变量拟合后报告间接效应。

编号模型由规格编译为各内生变量的 OLS/logistic 方程，并枚举所有
X→…→Y 有向间接路径。特定间接效应、总间接效应及其条件形式使用明确记录种子、
次数和区间方法的 Bootstrap；引擎提供的区间方法为 `percentile` 与
`bias_corrected`——后者只做 z0 偏差校正、不含 jackknife acceleration，
是 BC 而非 BCa，结果中的 `bootstrap_bias_corrected` 命名不得解读为 BCa。
文档其余位置出现的 BCa 字样均指官方 PROCESS 宏 oracle 参考输出使用的区间方法，
不代表本引擎可产出 BCa。代表性调节值采用第 16、50、84 百分位和 type-6
分位数定义。同一路径同时含 W、Z、W×Z 时，简单斜率必须使用完整的联合梯度和
系数协方差矩阵，不能把两个调节变量分别探查后拼接。只有单一线性调节路径适合
Johnson–Neyman 区间；高阶条件间接效应报告 W、Z 网格及多项式系数。一次项可
对应常见线性调节中介指数，W²、W×Z 等项不得写成单一线性指数。

数值验证至少包括：全部 55 个编号及允许的多中介变体可执行；每个回归方程与
独立 NumPy 最小二乘结果一致；复杂模型的 Bootstrap 有有限、排序正确的区间。
官方 PROCESS for R 5.0 宏不随仓库分发。需要重建独立金标准时，研究者须通过
`RESEARCHPATH_PROCESS_MACRO` 或生成器首个参数提供其有权使用的本地副本；当前校验
副本的 SHA-256 为 `3D02E6BBEC08A4A3EE9EDEB8E6300678D717A7A08E41E11C8149C04AB64B8648`。
执行前必须通过 `engine/R/lib/process5_standard.R` 的模型编号、中介数量、变量角色、
变量编码和特殊调节规则守门；执行结果的 `provenance.processReference` 必须记录
参考包名称、版本、外部来源、哈希、本地可用性、官方模型矩阵和特殊规则。Model 83/86 的 W
只作用于首个中介方程，Model 87/90 的 W 只作用于最后一个中介至 Y 的方程，Model
91/92 按官方 `wcmat` 规则要求 W 并作用于串联中介边；这些约束不能由通用图形推断
覆盖。当前 ResultBundle 使用结构化快速估计器适配标准模型矩阵，不承诺复刻官方宏的
文本排版或全部选项；需要逐字官方输出时，必须在官方许可范围内另行运行本地副本。二元结局使用
logistic 路径时，不把系数解释为线性概率效应，也不把横截面路径乘积直接写成因果机制；
结果同时提供连续预测项的导数 AME、二元预测项的 0→1 离散 AME，以及名义预测项相对事前参考水平的离散对比 AME，明确 `estimand`、参考/对比水平、尺度、
区间和方法；区间统一使用请求的 `confidenceLevel`。HC3 必须使用未裁剪的 `(1-h_i)^{-2}` 定义；当设计矩阵欠秩、杠杆值趋近 1 或协方差不可计算时必须拒绝伪 HC3 并标记回退与人工复核。模型边、间接效应、条件效应与假设必须在 `evidenceGraph` 中绑定同一
edge/hypothesis/estimand 身份，图、表、解释与导出不得各自生成不一致的名称。

HC3 的 external covariance evidence 当前同时覆盖 OLS 与确定性的 binomial GLM，并与 `sandwich::vcovHC(..., type="HC3")` 逐元素比较；该验证增强 execution evidence，不改变 HC3 的产品边界、公式或 publication gate。

SEM 报告至少区分：

- 模型语法和估计器；
- 收敛与异常解；
- 拟合指标；
- 标准化/非标准化路径；
- 间接效应和 Bootstrap；
- 多组约束或测量等值性层级。

SEM 还必须保存独立数值参考矩阵：连续题项的 ML/MLR、有序题项的 WLSMV、FIML 缺失、
invariance 阶梯，以及 Heywood、非正定和不收敛失败状态。异常解或失败结果统一
`publicationEligible=false`、`requiresManualReview=true`；横截面 SEM/PROCESS 的 claim
mode 只能是 association，不生成 temporal precedence、experimental effect 或 causal wording。MLR 是独立可请求估计器，不得只在说明文字中出现；每次结果保存 requested/executed estimator、requested/executed missing 及冻结参考 fixture ID。

SEM 的 confidence-level ownership 已验证为 level-driven critical-value plumbing。SEM 的 90%/95%/99% execution conformance matrix 已冻结：`semResult.loadings`、`semResult.paths` 与多组路径差异均按请求 `confidenceLevel` 计算正态/Wald 区间，并以区间宽度严格嵌套测试守门；SE 不可用时区间置 null。上述区间进入公开结果契约、前端展示与 APA/导出表，表头必须显示实际置信水平。多组等值性分支内部的载荷/路径 CI 维持既有实现；若 Publication Layer 扩展估计器或区间方法，仍须另行定义覆盖契约。provenance 的 `standardErrors` 记录实际执行的 SE 设置（standard/robust/bootstrap），requested/executed 同时保存在 `numericReferenceMatrix.execution`；`seed` 仅在 bootstrap 实际执行时报告，否则为 null，不再使用固定占位值。

## 纵向与日记/ESM

纵向面板支持观测或潜变量 CLPM、RI-CLPM、LCM-SR、纵向测量等值性、ULMC 敏感性和 Monte Carlo 功效。时间点、波次样本流、缺失和竞争模型必须报告。

纵向和日记/ESM 请求必须与横截面基础推断隔离：界面不得继承或隐藏提交组间、单层回归、控制变量和响应面默认值；API 必须枚举同一请求实际包含的全部 capability slice，并拒绝与 panel 或 intensive-longitudinal 上下文不相容的横截面 slice。R 基础链路将 panel、intensive-longitudinal 与 nested 行结构统一视为非 IID；普通逐行相关 p 值/Fisher 区间、Bartlett 参考分布、逐行 HTMT bootstrap、普通测量等值性、单层回归和响应面不得执行。描述和 EFA/CFA 载荷只能标为测量准备，正式推断来自显式选择且匹配依赖结构的纵向或多层模型。

日记/ESM 支持两层 Gaussian LMM、二元/计数/零膨胀/Hurdle GLMM、交叉分类、观测变量 Bayesian DSEM、多层中介、二层 MI 和功效。中心化规则必须区分：

- CWC：个体内中心化；
- CGM：总体均值中心化；
- 个体均值：用于分离 within/between 效应；
- 时间与滞后变量：必须说明排序、间隔和首期缺失。

重复的数据准备和中心化逻辑应集中到共享 R helper；新增 diary 方法不得复制一套近似实现。

## 实验、功效和通用 MI

随机实验设计当前边界：长格式 factorial ANOVA/ANCOVA、单一组内因子重复测量与混合设计、cluster-robust Gaussian GLM，以及对应的 EMM、Games–Howell、CI、Greenhouse–Geisser和计划对比。它们仅对声明随机分配且满足适用性契约的切片开放。计划对比的 p 值仅在显式 `multiplicityFamilyId` 内按 Holm 或 BH 校正，单个区间保持未同时校正并显式披露。当前不生成操纵检验、基线平衡结论或 CONSORT 样本流；不从最终分析数据反推失访/排除为 0，也不以此替代准实验识别。

通用功效当前边界：回归 Cohen f²/R² change、单样本/两独立样本 t、均衡组间 ANOVA 的解析功效；Gaussian 回归与均衡 ANOVA Monte Carlo；样本量/效应量反解、MCSE、Wilson 区间、CI 宽度和 MDES。

通用 MI 当前边界：类型感知 MICE、与显式下游线性回归规格绑定的不可变插补数据集、逐份拟合、Rubin 合并、FMI 和 Barnard–Rubin 自由度。每个插补模型必须包含核心分析的 Y、预测变量和协变量；验证规格保存该模型规范化 JSON 的 SHA-256 指纹，保存指纹与当前模型不一致时必须重新插补。它不等于任意下游模型的自动合并。

MI 多变量诊断能力边界：产品结果中的 Rubin 合并诊断仅包含逐系数 FMI/RIV/Barnard–Rubin 自由度，不包含 D1/D3 多变量检验。未来若增加多变量合并检验，必须先定义公开结果契约、方法参考与独立验证证据，本段边界才可改写。

## 方法专属图形的证据规则

- MICE 链图只在结果包含逐次迭代链值时绘制；
- Monte Carlo 功效曲线只连接实际返回的样本量/功效点；
- Bifactor 卡片、IRT 题目区分度和 DIF 图只展示估计器返回的题目级或模型级指标；
- 字段不足时展示缺失边界和下一步，不生成示例轨迹、插值统计量或模拟结论；
- 图、表、文字解释和导出必须引用同一结果 bundle。

## 最低报告字段

每个结果 bundle 应能回答：

1. 用了哪个数据版本和规格；
2. 实际执行了什么方法；
3. 有多少观测进入分析；
4. 关键估计、标准误/区间和效应量是什么；
5. 有哪些警告、回退和诊断；
6. 如何用相同版本、参数和种子复现。

## 可追溯报告事实与披露画像

基础模型、实证中心和高级分析的结果在生成解释文本前都必须附加 `reportFacts`。每条事实只保存稳定 ID、事实类型、展示标签、JSON Pointer 来源和结果对象身份，不复制估计值；报告中的“来源索引”也只引用这些指针。消费者必须在当前结果对象上解析指针，因而源字段改变、删除或结果身份变化都不能被旧的摘抄值掩盖。`reportFacts` 是可审计引用层，不改变估计量、不替代原始结果字段，也不构成结论正确性的认证。

`specs/reporting-profiles.json`（schema 同目录）定义对齐 APA JARS-Quant、STROBE、CONSORT 2025 与 AEA data/code 的四类机器可核验披露子集。每个画像都以 `scopeNote` 明示它不是相应规范的完整清单或合规认证；画像只逐项检查结果中是否存在可解析的结构化证据，并输出适用性、完整度与缺失项，其固定用途是 `disclosure_completeness_only`。系统不得据此自动声明研究质量合格、因果效应成立或授予发表资格，对应三个认证标志始终为 `false`。CONSORT 所需参与者流、随机分配与排除事实若未真实采集，必须报告缺失，不得从最终分析样本反推或补零；AEA data/code 画像同样不把“有导出文件”推断成许可、可执行环境或独立复现已完成。

### 回放包与三层发表门禁

基础模型与高级分析导出包包含哈希 manifest、重放脚本、标准库 Python 校验器，并按 RO-Crate 1.3 attached-package 规则在包根目录写 `ro-crate-metadata.json`。校验器必须能在解压后的干净临时目录逐文件验证 SHA-256，并对缺失、越界路径或内容篡改 fail closed；RO-Crate 元数据记录命令、数据是否随包、manifest 和校验器关系。仓库及用户数据没有可验证许可时必须写 `NOASSERTION`，不得推测许可证。基础实证中心尚无等价的代码+数据回放包，因此结果显式 `replay.available=false`，AEA 画像的 replay 项保持缺失。

包已生成只表示材料已封装，哈希通过只表示字节未漂移；两者都不等于统计结果被独立复现。单次结果中的 `cleanRoomVerified` 默认固定为 `false`，只有在该具体包的隔离环境重放、结果比较与审计记录真正完成后才可由独立流程确认。自动测试只认证封装与校验机制，不回填用户包的 clean-room 状态。

`publicationGate` 把最终资格拆成三层：① capability layer 读取实际执行切片的 validationLevel，只有全部 `externally_validated` 才通过；② run evidence layer 要求成功运行、显式估计成功、推断可靠、结果/数据身份绑定、无阻断错误且该具体包完成 clean-room replay；③ reporting layer 要求所有适用披露画像完整。三层全部通过后仍只能进入 `requires_human_confirmation`，必须有具名、带时间的人工确认才可令 `finalEligible=true`。任何单层失败、内部验证、缺失回放或默认无人确认都 fail closed。既有顶层 `publicationEligibility` 仅表示统计状态模型的条件性判断，不能替代三层最终门禁。

规范参考（画像仍只是机器可核验子集）：[APA JARS](https://www.apa.org/pubs/journals/resources/apa-style-jars.html)、[STROBE](https://www.strobe-statement.org/)、[CONSORT 2025](https://www.bmj.com/content/389/bmj-2024-081123)、[AEA Data and Code Policies](https://www.aeaweb.org/journals/data)、[RO-Crate 1.3](https://www.researchobject.org/ro-crate/specification/1.3/index.html) 及其 [GitHub specification repository](https://github.com/ResearchObject/ro-crate)。

尚未具备外部对照的边界（如实记录，不以此升级 validationLevel）：

- generic 编号 28/29 与 60-92 的其余拓扑差异仅共享模型 60 的机制级对照，未逐一对照；
- EFA/CFA/IRT/DIF、纵向面板、DSEM 等高级方法仍为内部验证，对应能力注册表的 `validationLevel` 不得高于其实际证据等级；
- 分组二项(cbind 形式,如 cbpp)在日记 GLMM 路径不可表达,属已声明编码边界(仅 0/1 结局)。
