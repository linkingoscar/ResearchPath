# 活动实证功能目录与路线图

> 状态日期：2026-08-24。本文是当前用户可达、可由活动代码执行的统一实证功能目录。活动代码、测试、capability registry 与 `specs/capability-evidence.json` 优先于本文；`archive/` 中的资产和历史记录不能作为功能已上线的证据。

## 如何阅读本目录

- `active`：用户可从当前前端入口进入，真实数据可走到活动 R/Python 链路，结果以持久化报告或任务结果呈现。
- `experimental`：当前可执行，但只覆盖表中写明的规格切片；必须保留警告、诊断、实际执行方法和导出证据。
- `validated`：`validationEvidence` 已通过 contract、适用性和失败边界 gate；仍不等于整篇论文的主分析资格。
- `reviewer_ready`：额外通过独立 external oracle 与 numeric golden；仍需论文级 evidence manifest/publication gate。
- `publication_ready`：能力层只有在外部验证齐备且后续结果级发表门禁通过时才可能派生。当前没有活动切片处于此状态。
- `识别可用 / 估计未开放`：可识别、保存或导出设计，不能提交运行。
- `deferred` / `dormant`：不属于当前产品能力，不应在界面、报告或销售表述中写成可用。

所有分析都绑定数据版本、测量版本（如适用）、规格、随机种子和引擎输出。前端只格式化和展示结果，不重新计算统计量。

## 能力成熟度与论文资格

每个 capability slice 返回三个互不替代的字段：

| 字段 | 回答的问题 | 当前规则 |
| --- | --- | --- |
| `executionAvailable` | 当前 R/Python runner 能否执行？ | 是全局执行门槛，仍需当前上下文适用。 |
| `validationLevel` | validation evidence 完成到哪一层？ | `unvalidated`、`internally_validated`、`externally_validated`。 |
| `validationEvidence` | gate 使用哪些可复现证据？ | contract tests、applicability tests、failure fixtures、external oracle、numeric golden。 |
| `maturityLevel` | 当前切片完成到哪一层验证？ | `experimental`、`validated`、`reviewer_ready`、`publication_ready`。 |
| `publicationEligibility` | 能力或统计状态层是否具备继续审查的条件？ | `ineligible`、`conditional`、`eligible`；它不是最终发表批准。 |
| `publicationGate` | 这一次结果能否进入人工发表确认？ | 分别检查能力验证、单次运行证据、稿件披露；最后仍要求具名人工确认。 |

`executionAvailable=true` 绝不自动推出论文级资格；成熟度由 validation evidence gate 派生，不能仅把 slice ID 加入 allowlist。结果级 `publicationGate` 已实现三层 fail-closed 判定：能力切片必须全部 external、该次运行必须可靠且完成具体回放包的 clean-room verification、所有适用披露子集必须完整；三层全过后仍需具名带时间人工确认。当前运行时默认没有 clean-room 证明和人工确认，因此不会自动产生 `finalEligible=true`，能力目录也仍无 `publication_ready/eligible` 切片。

能力证据的机器可读单一来源为 `specs/capability-evidence.json`，并由 `specs/capability-evidence.schema.json` 约束。39 个活动切片逐项登记 estimand 状态、支持的数据结构、假设、诊断、oracle 独立性、测试证据、限制与版本；registry 的 validation evidence 直接从该 manifest 派生。schema、切片全集、结构边界或成熟度证据发生漂移时，API 门禁必须失败。`not_formally_frozen` 明确表示可执行切片尚无完整可认证估计目标，不能由通用描述补写为论文主分析资格。

当前证据分布为：26 个 `unvalidated/experimental`、9 个 `internally_validated/validated`、4 个 `externally_validated/reviewer_ready`。外部验证组包括 PROCESS 目录，以及回归、单/双样本 t、均衡组间 ANOVA 三项解析功效切片；后者由不调用产品 R runner 或 `pwr` 的 Python/SciPy 非中心分布 oracle 生成冻结金标准。所有 13 个非实验性切片仍为 `conditional`，没有切片自动获得最终论文发表资格。

## 共同前置：数据、变量与测量

| 环节 | 当前能力 | 前置 / 使用方式 | 生成物与边界 |
| --- | --- | --- | --- |
| 数据导入 | CSV、XLSX、SAV、DTA、POR | 在“数据与测量”拖放或选择文件；XLSX 可重选工作表 | 原始文件 SHA-256、本地只读数据版本；不原地覆盖原文件 |
| 数据画像与质检 | 行列数、缺失、唯一值、变量建议和数据质量工作区 | 导入后先检查，再进入变量确认 | 诊断用于决策，不自动修改原数据 |
| 变量字典 | 确认连续、Likert、二元、名义、顺序等类型 | 必须确认后才开放构念分组和计分 | 未确认变量不能绕过测量门禁 |
| 多源 / 多波次合并 | 合并多波次或其他数据源向导 | 在数据摘要处进入；应先明确匹配键和波次语义 | 生成新数据版本，不篡改原版本 |
| 测量版本 | 构念题项分组、反向题、计分、项目与基础信度诊断 | 数据字典确认后配置 | 派生 score variables；后续实证和模型画布使用明确的测量版本 |

## 横截面问卷实证

入口为“横截面问卷 → 问卷与实证分析”。配置区有引导模式和专家模式：前者按研究问题推荐方法并显示前置条件，后者可展开全部当前设置。点击“运行问卷实证分析”后，结果页只将本次报告实际包含的 segment 标为“有结果”。

| 功能 | 配置入口 | 可执行内容 | 结果 | 边界 |
| --- | --- | --- | --- | --- |
| 描述、缺失与分布 | 基础分析与样本 | 样本规模、缺失、描述统计、偏度/峰度、因子分析适切性 | `描述与正态性` | 分布诊断不是自动删样本或变换命令 |
| 相关分析 | 基础分析与样本 | Pearson、Spearman、基于控制变量的偏相关；显式选择 none/Holm/BH，默认 BH | `相关与矩阵`、热图和虚拟化相关表；raw/adjusted p 与 family 证据 | 相关不自动表述为因果；nested 只显示描述系数，不生成逐行 p/普通区间 |
| EFA | 测量模型 | Varimax/Promax；Kaiser、平行分析或手动因子数 | 载荷、共同度、结构矩阵、因子相关、碎石图 | 完整案例或题项变异不足时明确不可用；回退必须标明实际方法 |
| CFA 与基础信效度 | 测量模型 | CFA、α、ω、CR、AVE、Fornell–Larcker、HTMT Bootstrap CI | `信效度 (EFA/CFA)` | 连续 MLR、有序 WLSMV；混合尺度无显式异质相关规格时拒绝；HTMT 披露 Pearson/polychoric 来源；高级 ESEM/Bifactor/IRT/DIF 不在基础报告自动执行 |
| 组间差异 | 基础分析与样本的组间差异变量 | 两组/多组比较、效应量、Welch/Brown–Forsythe、Tukey/Bonferroni/Games–Howell；跨构念 family 默认 Holm | `组间与聚合` | 未选择 `groupVariableId` 即为“未配置”；nested 阻断普通组间检验；raw/adjusted p 同时保存 |
| 聚合诊断 | 独立的 cluster 聚合变量 | ICC(1)、ICC(2)、设计效应、rwg(j) | `组间与聚合` | `aggregationVariableId` 不替代组间比较变量；只提供聚合证据，不自动把数据升级为多层因果结论 |
| 多组测量等值性 | 分组变量 + 测量模型 | 当前报告中的多组测量等值性结果 | `信效度 (EFA/CFA)` | 分组变量和测量结构必须明确；结果与独立高级测量工作台的等值性规格不同，不能混用 |
| 分层 OLS 回归 | 回归与高级分析 | 区块 1 控制变量、区块 2 核心预测构念、ΔR²/F-change、系数、VIF、f²、置信区间 | `分层回归` | 必须先选结果变量和至少一个预测变量；未配置时明确显示“本次未生成分层回归” |
| 回归稳健性与相对重要性 | 回归与高级分析 | 已返回的稳健性诊断；多预测变量时的相对重要性 | `分层回归` / `高级与稳健性` | 仅消费本次报告字段，不合成图或数值 |
| 响应面分析 | 回归与高级分析 | 两个预测变量的响应面规格与结果 | `高级与稳健性` | 必须显式选两个预测变量；不是任意多变量非线性建模平台 |

## 纵向面板

入口为“纵向面板 → 纵向面板分析”。用户应先声明被试 ID、波次、时间值、观测得分或题项级潜变量结构，再选择模型；结果位于独立“纵向面板”页签，数据源是持久化报告 segment。

配置工作流按研究范式隔离：横截面页展示相关、多重性、组间、聚合和回归控件；纵向/日记页只展示样本与非 IID 边界，再进入 `LongitudinalPanelConfig` 或 `DiaryMultilevelConfig`。范式切换会清空不可见的横截面选项，服务端再次按实际 slice fail-closed，R 引擎最后阻断逐行横截面推断。三层边界共同保证“未显示、未请求的方法不执行”。

| 功能 | 前置与配置 | 当前输出 | 边界 |
| --- | --- | --- | --- |
| 波次映射 | 被试 ID；每波 X/Y 变量或等价题项；可设置不等距 `timeValue` | 波次样本流和规格记录 | 波次语义不能由列名猜测替代 |
| 传统 CLPM | 至少 2 波；观测得分或题项级结构 | 自回归、交叉滞后、缺失策略和诊断 | 当前前端说明两时点可启用；复杂设计解释仍需研究设计支持 |
| RI-CLPM | 至少 3 波，推荐的默认模型 | 随机截距、个体内自回归/交叉滞后、竞争与稳健性模型 | 仅限当前声明的双构念结构和估计边界 |
| LCM-SR | 至少 5 波；题项级潜变量；线性或二次宏观生长 | 宏观增长与结构化残差动态结果 | 不等于任意潜变量动态 SEM |
| 纵向测量等值性 | 至少 2 波、题项级潜变量；configural/metric/scalar/strict，可选部分等值 | 级联检验与潜均值比较（适用时） | 题项尺度、估计器和缺失处理须在规格中明确 |
| 纵向 ULMC、竞争模型与功效 | 在相应设置启用 | ULMC 敏感性、竞争/稳健性模型、Monte Carlo 功效/偏差/覆盖率 | 仅报告实际配置和成功运行的模块 |

估计器与缺失处理会随题项尺度变化：连续题项可选 ML/MLR 与 FIML/完整案例；有序题项走 WLSMV 和相应完整案例口径。模型能计算不代表波次可比性、样本流或缺失机制已经得到理论保证。

## 高级工作台：实验性但可运行的受限切片

进入顺序固定为“实验设计 → 通用功效与精度 → 通用多重插补 → 高级问卷测量”。每个方法均经过：**规格配置（向导或高级 JSON）→ 验证规格与警告 → 提交后台任务 → 进度/取消/会话恢复 → 结果与可追溯导出**。以下全部为 `experimental`，不得泛化超出登记边界。

### 实验设计

| 可执行切片 | 当前范围 | 主要结果 / 辅助证据 |
| --- | --- | --- |
| 长格式 factorial ANOVA | 单一 outcome、最多 3 个组间因子；单一组间因子可用真实 Games–Howell | ANOVA、EMM、CI、计划对比和适用事后比较 |
| 长格式 ANCOVA | 单一 outcome、长格式 | ANCOVA；协变量×处理交互仅生成警告 |

| 单一组内因子混合设计 | 一个 within factor | EMM/CI、Greenhouse–Geisser、空/缺失单元边界 |
| 长格式 cluster-robust Gaussian GLM | 单一 outcome、identity-link Gaussian lm、CR0 cluster-robust SE | 聚类稳健双侧推断；临界值使用 `1-(1-confidenceLevel)/2`；不冒充 CR2 或 GLMM |

## 不属于当前可用范围

- 任意未在 registry 登记的高级方法组合；
- 任意未命中 PROCESS 5.0 编号的自定义拓扑直接运行；
- 三层或任意交叉分类结构、通用广义多层中介、连续时间模型、潜变量/高阶动态 SEM；
- 通用 MI 对任意下游模型的自动合并；
- 准实验因果识别：fixed effects、DiD/event study、IV/2SLS、RDD、IPW/overlap、synthetic control；
- 研究项目、预注册、协作、云端账户、遥测和远程同步；
- 资产包中的研究项目、认证实验室或旧原型。
