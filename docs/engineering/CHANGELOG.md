## 未发布 · CI 分级与 R 安装检查

### 修改

- 日常 PR 和 main 推送接入同一影响解析器，按 Quick / Targeted / Full 三档执行；保留手动 Full 与依赖审计。
- Quick 用于小改动。中等单一功能的 Targeted 命令包含一次 Quick，再传入相关模块的具体 API/Web/R/E2E 文件。
- 跨域、统计/契约根基、共享安全/运行基础设施、未知范围和缺失测试映射直接进入 Full；解析发生在执行 Quick 之前。
- 比较基准使用 PR base SHA 或 push before SHA；完整历史和直接树比较覆盖多提交推送、历史改写及重命名两侧。
- 选择器拒绝空、越界及不存在的文件；API 模块测试串行兼容 serial 标记，R 保留 GLMM 隔离，相关 E2E 前构建生产前端。
- 测试文件随所属模块解析；同一模块的源码与测试联合改动保持 Targeted，通用目录不会带入专用模块的测试。
- 分级与选择器回归测试归入 Full，避免为小改动增加另一套常驻门禁。
- R 源码安装前检查真实路径；非 ASCII 路径给出直接错误，不更改依赖锁或统计容差。路径限制及处理方式见运行维护文档。
- 同步仓库指南、工程验证规范和运行维护说明，建立独立债务登记。
